# Archived Documentation

This directory contains older documentation files that have been consolidated into the main documentation.

## Why These Files Are Archived

These files were created during the development of various BunTool features and contained detailed implementation notes, technical specifications, and development progress documentation. While valuable for historical reference, they created confusion with multiple overlapping documents.

## Current Documentation Structure

All tool documentation has been consolidated into:

**Main Documentation** (in root directory):
- **[README.md](../../README.md)** - Main project documentation with installation and overview
- **[TOOLS.md](../../TOOLS.md)** - Complete consolidated guide for all tools and features
- **[QUICK_START.md](../../QUICK_START.md)** - Quick start guide for custom numbering
- **[USAGE_EXAMPLES.md](../../USAGE_EXAMPLES.md)** - Real-world usage examples
- **[DOCKER.md](../../DOCKER.md)** - Docker deployment guide
